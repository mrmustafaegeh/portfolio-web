# 🌐 Mustafa Egeh - Full Stack Portfolio Project

This repository contains the full source code for my professional portfolio ecosystem, comprising a high-performance **React Frontend** and a robust **Express.js Backend**.

## 🏗 Project Structure

- **`/frontend`**: The user interface built with React, Vite, and Tailwind CSS. Featuring premium glassmorphic design and smooth animations.
- **`/backend`**: The API service powering project data and potentially dynamic features, built with Node.js, Express, and MongoDB.

## 🚀 Quick Start

To run the entire ecosystem locally:

### 1. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### 2. Backend Setup
```bash
cd backend
npm install
npm start
```

## ✨ Key Features
- **AI Integration**: Blog summarization using GPT-4.
- **High Performance**: Redis caching and optimized React components.
- **Premium UI**: Custom-built aurora backgrounds and interactive sections.
