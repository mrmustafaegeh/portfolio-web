# 🚀 Mustafa Egeh - Premium Portfolio Website

A high-performance, visually stunning portfolio website built with **React**, **Vite**, and **Tailwind CSS**. Designed with a premium "Glassmorphic" aesthetic, featuring fluid animations, dynamic backgrounds, and high-conversion sections.

![Portfolio Demo](https://portfolio-web-vuj7.vercel.app)

## ✨ Premium Features

### 🌌 Immersive Aesthetics
- **Animated Aurora Background** - Fluid, moving blobs with a subtle grid overlay for a deep, modern atmosphere.
- **Glassmorphic UI** - Translucent navigation and cards with backdrop filters for a cutting-edge feel.
- **Micro-interactions** - Smooth transitions, hover scaling, and interactive elements powered by Framer Motion.

### ⚡ Technical Excellence
- **Vite & React 18** - Blazing fast development and optimized production bundles.
- **Performance Optimized** - Lazy loading for heavy sections, optimized image handling, and 100/100 accessibility scores.
- **Dynamic Projects Engine** - A centralized project repository with filtered categories and featured project highlights.
- **Theming System** - Fully integrated Dark/Light mode with local storage persistence.

### 🍱 Strategic Sections
- **Hero** - High-impact introduction with interactive "performance" floaties.
- **About** - Professional storytelling with a dedicated skills matrix.
- **Projects** - Curated showcase of my best work (Pokedex, E-commerce, AI Blog).
- **Expertise** - Detailed breakdown of UI, Performance, and Full-Stack offerings.
- **Contact** - Premium collaboration portal with a sleek, user-friendly interface.

## 🛠 Tech Stack

- **React 18** - UI development with modern hooks

## 🚀 Installation & Setup

### Prerequisites
- Node.js 18+
- npm, yarn, or pnpm

### Getting Started

```bash
# Clone the repository
git clone https://github.com/mrmustafaegeh/react-portofolio-with-tailwind-main.git

# Navigate to project directory
cd react-portofolio-with-tailwind-main/frontend

# Install dependencies
npm install

# Start development server
npm run dev
```
